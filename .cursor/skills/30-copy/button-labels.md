# Button labels workflow

## Use for
- button text
- CTA labels
- confirm/cancel pairs
- menu action labels

## Rules
- Use a verb-first label when possible.
- Keep labels short and specific.
- Reflect the real outcome, not intent alone.
- Prefer one primary action per view.
- Keep paired actions distinct (for example: Save / Cancel).

## Patterns

- Primary action: `Save changes`, `Create agent`, `Send`
- Secondary action: `Cancel`, `Back`, `Close`
- Destructive action: `Delete file`, `Remove member`

## Examples

- current: "Submit"
  proposed: "Send request"
  why: "More specific outcome"

- current: "OK"
  proposed: "Save changes"
  why: "Clarifies action"

- current: "Yes"
  proposed: "Delete forecast"
  why: "Explicit destructive action"
