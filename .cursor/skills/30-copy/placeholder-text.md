# Placeholder text workflow

## Use for
- brief input examples
- expected format cues inside empty fields

## Rules
- Keep placeholders short.
- Use placeholders as examples, not instructions.
- Never rely on placeholder as the only guidance.
- Use realistic sample formats.
- Avoid complete sentences when a compact example works.

## Pattern

`Example value` or `Expected format`

## Examples

- net-new: `name@example.com`
- net-new: `Search by name or ID`
- net-new: `MM/DD/YYYY`
- net-new: `https://company.example/webhook`

## Avoid
- "Enter value here"
- Long instructional text in placeholder
- Fake Latin or temporary filler
