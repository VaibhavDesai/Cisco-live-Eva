# Helper text workflow

## Use for
- inline field guidance
- clarifying what to enter
- short "how this works" hints near controls

## Rules
- State what the user should do now.
- Explain format or constraints only when needed.
- Keep to one sentence when possible.
- Put key requirement first.
- Avoid directional references (for example: "see below").

## Structure

`Action + format/constraint + outcome`

## Examples

- current: "Please provide your work email address in this field."
  proposed: "Enter your work email"
  why: "Direct and shorter"

- net-new:
  proposed: "Use at least 8 characters"
  why: "Clear requirement, no fluff"

- net-new:
  proposed: "Choose a timezone to schedule notifications correctly"
  why: "Tells user why this matters"
