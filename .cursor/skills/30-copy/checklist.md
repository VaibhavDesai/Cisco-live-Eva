# Copy quality checklist

Use this checklist before returning final copy.

- [ ] The copy matches user goal and UI context
- [ ] The wording helps users take a clear next step
- [ ] Sentence case is used
- [ ] Language is concise and plain
- [ ] No filler or placeholder text is present
- [ ] Tone is confident, human, and helpful
- [ ] No directional wording like "above" or "below"
- [ ] Error text includes a useful recovery step
- [ ] Button labels are specific and action-oriented
- [ ] Placeholder text is example-like, not instructional
- [ ] Phrasing is localization-friendly (no idioms/slang)
- [ ] Accessibility is respected (clear intent and outcomes)
